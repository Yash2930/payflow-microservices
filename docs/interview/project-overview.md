# PayFlow — Interview Notes

## What is PayFlow?

PayFlow is a digital wallet and payment platform
built using Java and Spring Boot.

The project is designed using a microservices architecture,
where different business capabilities are separated into
independently deployable services.

## Why did we build it?

The project is designed to simulate a real-world fintech
backend and demonstrate microservices, distributed
communication, asynchronous processing, security,
resilience, and deployment practices.

## Current Status

The project is currently under development.
